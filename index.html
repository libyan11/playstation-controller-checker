Before you start

  1. Use Chrome or Edge on a computer.
  2. Plug the controller in with a USB data cable. The real-or-fake checks need USB. The live tests, battery and Bluetooth signal tests also work over Bluetooth.

Recommended aim settings

Aim precision (right stick)

Step 1: push the right stick about a quarter of the way in any direction and hold it as still as you can. Step 2: move it slowly in a small circle, about a third of the way out. A healthy stick moves in tiny, even steps. A worn one jumps, which makes small aim adjustments jerky.

Battery

Charge
–

–

Controllers only report battery in 10% steps and don't report battery health. To judge the battery, run the monitor and leave this tab open. Plugged in, it times charging; on Bluetooth (unplugged), it times draining. A healthy controller charges from empty in about 2–3 hours and lasts about 4–8 hours (less with a bright lightbar).

Bluetooth

–

To test over Bluetooth, unplug the cable and press the PS button. If it isn't paired yet, hold Share + PS (PS4) or Create + PS (PS5) until the light flashes quickly, then add it in Windows Settings → Bluetooth & devices. Then click Connect & test again and pick it.

Signal test: once connected over Bluetooth, start this and move to where you normally sit (or further). It counts dropouts, meaning gaps of more than 50 ms with no updates, which you'd feel as stutter or lag.

Checks

How it works

DualShock 4 security chip (the strongest test): every genuine DS4 contains a Sony security chip so the PS4 can confirm it's authentic. This page runs the same handshake: it sends a random 256‑byte challenge, the controller signs it with its private RSA key, and the page checks the signature. Most clones don't have the chip.

DualShock Tools' clone checks: a genuine DS4 answers Sony's hidden 0x81 report instantly and returns a firmware report of exactly 49 bytes. A genuine DualSense answers Sony's stick-calibration query, returns a 64-byte firmware report, and never has a firmware date in the future. Both report a known circuit board (JDM-0xx for DS4, BDM-0xx for DualSense). These checks come from the open-source DualShock Tools project (MIT licence).

DualSense limitation: there's no public, verified way to run the PS5 security handshake, so DualSense results are a strong sign, not cryptographic proof.

Clues: factory sensor calibration, USB report rate (genuine controllers send about 250 updates a second), the internal sensor timestamp, analog triggers, every button, gyro, touchpad, RGB lightbar and dual rumble. Cheap clones usually fail several of these.

Third-party controllers: controllers like the Gioteck VX4 copy Sony's ID so a PS4 accepts them, but their hardware gives them away: the board doesn't match the model they claim, and their sensor calibration is a generic default instead of factory-measured. These checks work over Bluetooth too. Over USB on a PC, the VX4 acts as an Xbox 360 controller instead, so connect it over Bluetooth to test it here.

Condition, not authenticity: stick drift and deadzone show wear. A worn genuine controller can drift badly, and a new clone can have none.

Physical checks: a genuine controller's circuit board is printed JDM-0xx (PS4) or BDM-0xx (PS5), its screws and battery label look like Sony's, and it can wake a PlayStation from rest mode.

Limitation: Sony's root public key isn't published, so this page can't check Sony's signature on a DS4's certificate. A clone carrying a key copied from a real controller would still pass the handshake. That's rare in practice.
